# 会话级 SSH 连接隧道

新增或编辑会话时，可开启“SSH 连接隧道”，填写跳板机主机、端口、用户名及认证方式。默认关闭；支持密码、SSH 密钥、SSH Agent 和现有的交互式认证方式。

## 连接与测试

- 先连接并验证跳板机，再通过其 SSH `direct-tcpip` 通道连接目标；目标域名由跳板机解析，可使用仅内网可解析的域名。
- 这是会话的登录路径，不创建工具栏中的端口转发规则，也不监听本地端口。
- “测试隧道连接”使用当前未保存的跳板配置验证 SSH 登录，结果在表单内显示；不保存草稿、不打开目标终端。目标是否可达及其认证在正式连接时验证。
- 修改配置、切换会话或关闭表单会取消测试，旧结果不会覆盖当前表单。
- 正式连接显示可选的跳板步骤；两台主机的指纹都需要遵循现有信任策略。每次尝试使用独立 requestId，每端指纹使用独立 attemptId。
- 目标关闭、握手失败或操作取消时，回收跳板连接和转发任务；重连重新建立整条路径。

## 保存与安全

- `Session.JumpHost` 为空表示禁用，旧数据库和旧备份迁移后保持直连。
- 跳板密码沿用现有加密存储与主密钥轮换。普通会话 API 和前端列表不保留密码。
- 编辑时留空仅对相同主机、端口、用户名及认证方式保留原密码；禁用或切换非密码认证会清除不再使用的凭证。
- 会话复制与加密备份包含跳板配置。CSV 沿用已有字段格式，覆盖更新已有会话时保留其跳板配置。

验证覆盖数据库迁移、双端指纹、真实跳板到目标的终端、取消/失败回收、重试与迟到事件、密码轮换和加密备份恢复；提交前运行完整 `wails3 task ci`。
